Testing Report

Website validation notes

This page records the main manual checks for navigation, responsive behavior, search filtering, forms, and accessibility.

Browser checks

Pages were checked for consistent navigation links, readable layouts, and responsive grids across desktop and mobile widths.

Interactive checks

The menu toggle opens and closes, jQuery search hides unmatched cards, and form submissions validate required fields and CAPTCHA answers.

Accessibility checks

Skip links, labels, visible focus outlines, semantic headings, and table headers are included for clearer keyboard and screen-reader use.

Known limitations

Forms are demonstration-only and show confirmation messages locally. A production version would connect submissions to a backend service.
